## Reproduction

```sh
npm ci
npm run lint
npm run typecheck
npm test
npm run build
npm run check:budgets
npx playwright install --with-deps chromium firefox webkit
npm run test:e2e
npm run test:e2e:cross
npm exec vite preview -- --host 127.0.0.1 --port 4173
# With preview running in another terminal:
npm run verify:production
npm run verify:crash
```

For this managed host only, WebKit uses `THREAT_HUNTER_WEBKIT_ROOT` and `THREAT_HUNTER_WEBKIT_LIBS` to select the installed MiniBrowser and verified user-local Debian libraries. This avoids privileged system modification; ordinary developer/CI hosts use the standard Playwright installation. No TLS/authentication protection is disabled. Browser configuration workarounds do not change shipped application code.

Automated axe results cover sampled home, Case File and debrief states with WCAG A/AA tags. Core-palette contrast tests verify declared color pairs. Neither constitutes a complete WCAG conformance claim or an assistive-technology review. Doubled-text and 320px reflow tests include portrait/landscape changes and case submission. Synthetic background events are distinct from physical OS interruptions.
